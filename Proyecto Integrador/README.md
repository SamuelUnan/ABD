# Proyecto Integrador

Sección dedicada al proyecto integrador del componente **Administración de Bases de Datos** (UNAN-Managua, 2° Semestre 2026). Define la ruta de trabajo para integrar, sobre la Base de Datos OLTP construida en el semestre anterior, los principios de administración de bases de datos: seguridad, políticas, manejo de roles y permisos, definición de triggers y tareas programadas.

## Documentos de la sección

| Documento | Contenido |
|-----------|-----------|
| [`00 - Contexto.md`](00%20-%20Contexto.md) | Antecedente, planteamiento, objetivo y alcance del proyecto integrador. |
| [`01 - Primer Corte Evaluativo.md`](01%20-%20Primer%20Corte%20Evaluativo.md) | Primer entregable (Semana 8): documento que detalla los ajustes de seguridad previstos para la base de datos. |
| [`02 - Segundo Corte Evaluativo.md`](02%20-%20Segundo%20Corte%20Evaluativo.md) | Segundo entregable (Semana 14): script de la base de datos con el cumplimiento de lo planteado. |

Cada entregable incluye su **rúbrica de evaluación** con escala de 2 a 5.
